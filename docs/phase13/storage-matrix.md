## What local testing can and cannot prove about Storage

This repository's local test harness (`supabase/tests/integration/`) runs
against PGlite or a plain native PostgreSQL instance, **neither of which
has Supabase Storage at all**. Every "signed URL" or "upload" behavior
claimed above is either a code-path inspection (confirmed the call exists)
or a pre-existing code comment (confirmed the intent), never a locally
executed Storage operation. **Real bucket privacy enforcement, signed-URL
expiry, upload size/MIME limits, and cross-AOC path isolation must be
verified against a real managed Supabase project in staging** — see
`rollout-runbook.md` step 9.
